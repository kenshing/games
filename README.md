# 🎮 games

聚会小游戏合集，每个游戏一个子目录，纯前端静态站点，构建后可直接部署。

## 游戏列表

| 目录 | 游戏 | 说明 |
| --- | --- | --- |
| [`witch-poison`](./witch-poison) | 女巫的毒药 🧪 | 藏毒、轮喝、惩罚轮盘的聚会整蛊游戏。支持双人对战 / 挑战 AI 女巫 / 3~6 人乱斗，真人语音播报，PWA 可添加到主屏幕离线玩 |

## 开发

每个游戏都是独立的 Vite + React 项目：

```bash
cd <游戏目录>
npm install
npm run dev     # 本地开发
npm run build   # 构建到 dist/，拖去任意静态托管即可上线
```

## 添加新游戏

在仓库根目录新建子目录，初始化一个静态站点项目（推荐同一套 Vite + React + Tailwind 模板），然后在上面的游戏列表里登记一行。
