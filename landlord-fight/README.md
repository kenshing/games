# 🃏 欢乐斗地主

经典三人斗地主，体验对标腾讯「欢乐斗地主」：真人语音播报、炸弹特效、倒计时托管、倍数结算一应俱全。

## 功能

- ✅ 完整牌型引擎：单张、对子、三张、顺子、连对、飞机（带翅膀）、四带二、炸弹、王炸
- ✅ 欢乐斗地主同款语音：叫分 / 牌型播报 /「不出」「要不起」/「我就剩一张牌啦」
- ✅ WebAudio 合成音效：发牌、甩牌、炸弹爆炸、飞机掠过、胜负旋律（无音频资源文件）
- ✅ 出牌特效：顺子/连对/飞机/炸弹/王炸 中央横幅动画，炸弹屏幕震动
- ✅ 倒计时闹钟：每手 15 秒，超时自动托管（能管则管，管不了不出）
- ✅ 倍数体系：叫分倍数 × 炸弹翻倍 × 春天/反春翻倍，实时倍数徽章
- ✅ 结算弹窗：胜负 + 倍数明细 + 每人积分变化
- ✅ 记牌器：一键开关，实时统计各点数剩余牌数
- ✅ 提示轮换：连点「提示」在所有能出的牌型间轮换
- ✅ 滑牌选牌：按住拖动即可连续选牌，单击微调
- ✅ 快捷聊天：「快点啊，等到花儿都谢了」等经典语录，AI 会回话
- ✅ AI 升级：领出会出顺子/飞机等组合牌型，农民配合、地主控场、残局搏杀
- ✅ P2P 联机：创建/加入房间三人对战（PeerJS）

## 运行

```bash
npm install
npm run dev     # 本地开发
npm run build   # 输出到 dist/
```
